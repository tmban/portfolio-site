What you're looking at
1
Drafts don't block the rest of the portfolio. A half-finished asset still exists as a real entity. Nav, reports and parents update around the partial record while the user finishes the long tail of detail.
2
Save state is explicit. Two prior steps carry a check and a timestamp. The user always knows what's committed, when it was committed, and which step the platform is sitting on now.
3
The step list shows what's left. "Save as draft" is a peer of "Continue", not a hidden link. The remaining steps are listed by name so users can stop at any point with no penalty.
