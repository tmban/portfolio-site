What you're looking at
1
The tree mirrors the URL. Whatever's expanded in the side-nav maps one-to-one with the path in the address bar. Linking, refreshing, and bookmarking all work without surprise.
2
The parent path is always visible. A user opening any deep entity sees its full ancestry — fund, property, building — alongside the URL, so context is never lost two clicks deep.
3
Permission rules inherit down. Roles set on a parent flow through every child unless explicitly overridden. The hierarchy is the access model, not a separate ACL the team has to keep in sync.
